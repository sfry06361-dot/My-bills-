## ✨ Core Features

* 🎬 **Auto-Play Startup Intro Video:** Automatically plays upon sign-in with animated multi-color scenes.
* 🎨 **Vibrant Multi-Color Design:** Distinct colors per tab, category, filter, and feature card.
* ⚡ **40 Interactive Features Hub:** Live financial calculators, instant bill insights, quick actions, and smart toggles.
* ⚙️ **10 Background Features Engine:** Automatic overdue scanner, advance notifier, daily digest synthesizer, Room mirror guard, currency cache sync, spending watchdog, duplicate detector, recurring predictor, cloud sync health monitor, and temp cache cleaner.
* 📅 **Interactive Calendar View:** Monthly view with color-coded due date indicators.
* 🔔 **Customizable Payment Reminders:** Set notifications 1, 3, 5, or 7 days in advance.
* 🌐 **10 App Languages & 💱 Multi-Currency Support:** USD ($), EUR (€), GBP (£), JPY (¥), AED, SAR, EGP.
* 💾 **Dual Storage Architecture:** Cloud Firestore (Google Sign-In) + On-device SQLite Room database.

## 🚀 Publishing on GitHub & Google Play

* **GitHub Actions:** `.github/workflows/build-apk.yml` builds a fresh `MyBillsReminder-APK` artifact on every push to `main`/`master`.
* **Google Play Store:** Build a signed Android App Bundle using `gradle bundleRelease` (or via Android Studio **Build > Generate Signed Bundle / APK**).
